# 인크루트 RSS와 사용자 입력 근거

현재 화면은 잡알리오·인크루트 **통합 검색**을 사용합니다. 이전의 출처 선택 화면은 제거했습니다. 사용 흐름과 API는 [경험 중심 상담 설명](preparation_coaching.md)을 참고하세요.

RSS는 공식 전체·IT·의료 피드 일부 공고이며 전체 채용시장 검색이 아닙니다. 공고 ID로 중복을 제거하고, 최신 성공 스냅샷의 명시적인 ID 목록을 15분간 재사용합니다. 피드에서 사라졌다고 마감·삭제 처리하지 않습니다. 연도가 빠진 날짜나 채용 시까지를 임의의 마감일로 바꾸지 않습니다.

서버가 인크루트 상세 페이지를 추가 수집하지 않습니다. 사용자가 원문을 확인해 모집 기간과 요건을 입력하거나 캡처에서 읽은 초안을 검토합니다. 이 내용은 공용 공고에 덮어쓰지 않습니다. 원문과 사용자 입력의 일치는 자동 검증하지 않습니다.

공식 RSS 안내: https://people.incruit.com/rss/rss.asp

피드: https://www.incruit.com/rss/job.asp / https://www.incruit.com/rss/job.asp?occ1=150 / https://www.incruit.com/rss/job.asp?occ1=190

## RSS 분야 근거 보존

공식 RSS 요청의 occ1 분야 코드는 job_posting.rss_categories에 보관합니다. 중복 공고도 분야 합집합을 유지합니다. IT 분야(150)라는 사실만으로 구체적인 IT 직무가 확인됐다고 단정하지 않으며, 공통 검색에서 분야 관련 후보로 표시합니다. 제목에서 구체적인 직무가 확인되면 우선 표시합니다. [공통 검색 기준](search_alignment.md)을 참고하세요.
