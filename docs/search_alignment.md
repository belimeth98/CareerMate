# 출처 간 공통 직무 검색

잡알리오·인크루트 RSS와 설정된 국내 기업의 Greenhouse·Lever에 같은 직무 규칙을 적용합니다. 검색 결과 수나 수집 모수가 같아지는 것은 아닙니다. 잡알리오는 현재 진행 공고를 페이지별로 수집하고, 인크루트는 공식 RSS에 노출된 일부 최신 공고를 사용합니다.

## 공통 분류

| 분류 | 제목에서 확인하는 표현 예시 |
|---|---|
| 소프트웨어 개발 | 백엔드, 프론트엔드, 소프트웨어, Python, 웹 개발 |
| 데이터·AI | 데이터 분석, 데이터 엔지니어, 인공지능, AI |
| 시스템·인프라 | 전산, 정보시스템, 클라우드, 네트워크, ERP 운영 |
| 정보보안 | 정보보호, 정보보안, 사이버보안 |
| 통신 | 통신설비, 통신기사, 정보통신 |

`IT`/`정보통신`은 위 분류를 포괄합니다. `백엔드`/`backend`는 백엔드 표현을 검색하며 프론트엔드나 일반직 공고로 자동 확대하지 않습니다. 근거가 없으면 정상 0건을 반환하고 기존 검색어 제안 기능을 사용합니다. 기본 직무 규칙에는 LLM을 추가 호출하지 않습니다.

## 매칭 근거와 정렬

검색 결과 각 공고의 `search_match`:

```json
{
  "level": "direct",
  "rank": 2,
  "categories": ["software"],
  "category_labels": ["소프트웨어 개발"],
  "reasons": ["제목의 직무 표현이 공통 검색 분류와 일치합니다."]
}
```

`direct`는 제목의 직무 표현 일치입니다. 원문 자격 충족이나 진행 상태 검증을 뜻하지 않습니다. `related`(rank=1)는 NCS 정보통신 또는 인크루트 IT RSS 분야만 일치하는 관련 후보입니다. 여러 직무를 묶은 공고일 수 있어 구체적 직무의 원문 확인을 안내합니다. 공통 분류는 앱의 검색용이며 RSS 공고에 NCS나 자격요건을 만들어 넣지 않습니다.

각 출처에서 모든 일치 후보를 정렬한 후 limit을 적용합니다. 통합 결과도 제목 근거를 분야 근거보다 먼저 정렬합니다. 같은 등급 안에서는 기존의 날짜 순서와 출처별 번갈아 배치를 유지합니다. 재계획에서 후보 수를 늘려도 같은 조건·캐시의 정렬 접두 부분은 유지됩니다.

일반 직무/회사명 검색은 제목·회사명을 대상으로 유지합니다. ASCII 검색어는 영문·숫자 단어 경계를 적용해 `IT`가 `Recruitment`, `AI`가 `Financial`, `Java`가 `JavaScript`에 잘못 일치하지 않게 합니다. IT 분류 판단에서는 회사명과 제목에 반복된 회사명을 직무 근거로 사용하지 않습니다. `개발`만 있는 제품·의료기기·지역 개발 등은 IT로 분류하지 않습니다. 의료 분야라도 제목에 소프트웨어 등 구체적인 IT 직무가 있으면 검색 가능합니다.

## RSS 분야 보존과 기존 DB

`job_posting.rss_categories`는 공식 RSS 요청의 occ1 코드 배열을 담은 JSON TEXT입니다. IT feed는 `150`, 의료 feed는 `190`이며 전체 feed는 분야 코드를 추가하지 않습니다. 한 공고가 여러 feed에 있으면 코드를 합집합으로 보존합니다. 다른 feed를 마지막으로 읽었다는 이유로 IT 분야 근거가 사라지지 않습니다.

기존 DB는 첫 RSS 검색에서 이 컬럼을 비파괴적으로 추가합니다. 예전 캐시에 분야가 없으므로 RSS snapshot을 오래된 상태로 표시하고 다음 refresh에서 공식 feed를 다시 읽습니다. 기존 프로필·경험·계획·공고 id·자격은 삭제하거나 덮어쓰지 않습니다. ALIO 검색은 컬럼이 아직 없는 DB도 읽을 수 있습니다.

화면에는 공통 분류, ‘제목의 직무 표현 일치’ 또는 ‘분야 관련 후보 · 직무 확인 필요’, 근거를 표시합니다. 답변에도 분야만 일치한 후보 수와 확인 안내를 포함합니다. 인크루트의 미확인 모집 기간·고용형태·상세 자격은 계속 원문 확인·사용자 입력을 사용합니다.

## 검증

```bash
python -B -m unittest discover -s test -p "test_search_alignment.py" -v
```

검증 대상: 제품개발/영문 부분 문자열/회사명 오탐, 출처에 공통인 분류, 좁은 직무의 무단 확대 방지, NCS/RSS의 관련 후보 표시, 중복 RSS 분야 합집합·저장, 기존 DB 마이그레이션, limit 전 우선 정렬, 통합 순서·재계획 접두 유지, 지역·snapshot 필터, 채팅 근거 전달, 미확인 자격 유지.
