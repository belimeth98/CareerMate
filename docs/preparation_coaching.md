# 통합 검색과 경험 중심 취업 준비 상담

## 목표와 사용 순서

이 서비스는 점수로 지원 여부를 판정하기보다, 경험을 정리하고 요건과 연결해 다음 준비를 정하도록 돕는다.

1. **프로필 만들기:** 프로필 이름·희망 직무 등을 입력한다. 프로젝트·업무·교육 경험을 경험 입력란에 작성하고 `경험을 새 프로필에 담기`를 누른 뒤 프로필을 저장하면 함께 저장된다. 프로필은 여러 개 만들 수 있다.
2. **프로필 선택:** 상담 화면의 `상담 프로필` 또는 내 프로필의 `저장된 프로필 선택`을 사용한다. 같은 희망 직무도 이름과 ID로 구분한다. 전환하면 새 상담을 시작하며 경험·일정은 해당 프로필에만 연결된다.
3. **경험 정리:** 내 프로필의 AI 경험 정리 도우미와 이야기한다. AI는 제공한 사실을 STAR(상황·과제·행동·결과)로 정리하고 모르는 내용을 질문한다. 초안을 가져온 후 사실·사용 기술을 검토해 저장해야 평가에 반영된다. 수치·기관·날짜를 만들어 채우지 않는다.
4. **통합 검색:** 잡알리오·인크루트 RSS를 한 번에 조회한다. 각 카드에 실제 출처와 원문 링크를 표시한다. 한쪽이 실패해도 확보한 결과를 표시하되 실패한 출처를 알린다. RSS는 일부 공고여서 전체 채용시장 검색을 보장하지 않는다.
5. **0건일 때:** 백엔드처럼 좁은 검색어는 IT·소프트웨어·정보통신·전산으로 넓혀 볼 수 있도록 버튼을 제공한다. 사용자가 버튼을 누른 뒤 검색하며 지역 등 다른 조건을 임의로 해제하지 않는다. IT 검색은 두 출처에 같은 공통 직무 분류를 적용한다. 제목의 직무 표현을 우선하고 NCS/RSS 분야만 일치하면 관련 후보로 구분한다. 단독 개발·회사명·영문 부분 문자열을 IT 근거로 쓰지 않는다. 자세한 기준은 [공통 검색 기준](search_alignment.md)을 따른다.
6. **경험을 먼저 확인:** 내부 참고 결과가 낮거나 필수 기술·자격의 미확인 경험이 있으면 점수를 먼저 보여주지 않고 추가 경험을 질문한다. 상담 채팅에 경험을 바로 이야기하면 검토용 초안을 만들 수도 있다. 저장한 경험으로 `상담 이어가기`를 선택하면 다시 확인한다.
7. **추가 경험 없음:** 버튼을 누르거나 `추가 경험 없음`, `없어요`라고 답하면 현재 정리한 경험 기준의 준비 방향과 참고 적합도를 안내한다. 경험을 새로 보태도 확인할 점이 남으면 추가 질문을 유지한다. 점수는 공고 카드의 접힌 상세 정보에 둔다.

낮은 결과를 먼저 보류하는 내부 기준은 필수 기술·자격 gaps가 있거나 확인 배점 대비 70% 미만인 경우다. 이 수치는 합격선이 아니다. `backend/app/fit_policy.py`에서 정책을 조정할 수 있다. 경험 부족을 능력 부재로 단정하거나 경험·자격을 만들어내도록 유도하지 않는다.

## 인크루트 모집 기간·요건·캡처

공고 카드의 `기간·자격요건 입력`을 누르고 원문에서 확인한 내용을 입력한다.

- 기간 확인: 모집 시작일·종료일을 입력한다. 시작 전·종료 후 여부와 미래 준비 계획의 완료 시점을 비교할 수 있다.
- 채용 시까지 또는 확인 못함: 해당 상태를 명시한다. 임의 날짜를 만들지 않는다. 마감일이 없으면 마감 전 성장 계획의 완료 여부를 판단하지 않는다.
- 기간만으로 현재 모집이 계속되고 있다고 확정하지 않는다. 입력 날짜는 사용자 입력 근거임을 표시하고 공용 공고에 덮어쓰지 않는다.
- PNG/JPG 캡처를 최대 2장 첨부하거나, 요건 입력 중 이미지 붙여넣기를 사용할 수 있다. 브라우저는 긴 변 2048px 이하로 조절한다. 서버 전송 기준 장당 3MB, 합계 5MB까지다. 필요한 부분을 크게 캡처하면 읽기에 유리하다.
- `캡처에서 초안 읽기`는 GMS 이미지 입력을 사용해 필수·우대요건과 모집 날짜를 읽는다. 연도·시작일 등이 잘리거나 읽히지 않으면 미확인으로 남긴다. 결과는 수정 가능한 텍스트와 날짜이며 자동 평가·저장하지 않는다.
- 사용자는 추출 결과와 원문을 비교해 수정하고 원문 확인에 체크해야 한다. 필수요건을 모두 입력했을 때만 전체 입력에 체크한다. 일부 요건이면 전체 자격을 확정하지 않는다.
- 입력한 텍스트와 이미지는 GMS로 전송된다. 연락처·지원자 개인정보는 제외한다. 서버는 이미지·요건 원문을 공고·평가 DB에 저장하지 않는다. 이미지·경험 코칭 호출의 LangSmith 추적을 비활성화하고 실행 로그에는 단계·상태만 남긴다.

## 데이터와 경험 반영

- 프로필에 `profile_name`, 경험에 `skills` JSON 배열을 추가한다. 기존 DB는 프로필·경험 API를 처음 사용할 때 필요한 컬럼만 추가하며 기존 행을 유지한다.
- 경험의 역할·상황·과제·행동·결과는 경험 기반 프로젝트 기준 비교에 사용한다. 사용자가 저장·확인한 사용 기술은 현재 보유 기술에 합쳐서 비교한다. 경력 개월 수나 자격·면허를 경험 문장에서 임의로 보유 처리하지 않는다.
- 새 프로필과 처음 담은 경험은 같은 트랜잭션으로 저장한다. 기존 프로필 경험은 개별 등록·수정·삭제한다. 타 프로필의 경험 ID로 수정·삭제할 수 없다.
- 인크루트 요건·모집 기간은 요청 내 평가 근거이며 공용 공고·평가 테이블에 저장하지 않는다. 잡알리오의 낮은 사전 결과는 경험 확인 전 match_result에 저장하지 않고, 확인을 마친 결과를 저장한다.
- 추가 경험 확인 대기는 같은 세션·프로필에 묶이며 30분간 서버 메모리에 둔다. 서버 재시작 시 대기가 초기화된다. 저장한 프로필·경험·지원 계획은 SQLite에 남는다.
- 이미지와 AI 초안은 브라우저/요청 내에서 처리하고 자동 영구 저장하지 않는다. 사용자가 확인한 경험만 저장 버튼으로 DB에 반영한다.
- RSS 스냅샷은 명시적인 공고 ID 목록으로 관리한다. 두 수집의 시각이 우연히 같아도 과거 목록이 섞이지 않는다. 기존 캐시 메타데이터는 다음 RSS 조회 때 갱신한다.

## API 변경

`POST /api/chat`의 기본 `job_source`는 `all`이다. 이전 저수준 Tool 호출 호환성을 위해 `search_jobs`의 기본값 `alio`는 유지하며 명시적인 alio/incruit 요청도 지원한다.

추가 응답: `fit_follow_up`, `search_suggestions`, `source_results`, `experience_draft`.

인크루트 요건 제출 입력:

```json
{
  "session_id": "my-session",
  "profile_id": 1,
  "message": "필수: Python, SQL. 우대: FastAPI 경험.",
  "requirements_job_id": 123,
  "original_confirmed": true,
  "requirements_complete": false,
  "recruitment_period_status": "provided",
  "recruitment_start": "2026-11-01",
  "recruitment_end": "2026-12-31"
}
```

ID는 실제 검색 결과 값으로 바꾼다. 날짜를 모르면 status를 `unknown` 또는 `until_filled`로 보내고 날짜는 생략한다. 모집 기간 확인 상태를 생략하면 422다.

추가 경험 없음: 같은 세션·프로필로 `fit_follow_up_action="none"`. 저장한 경험으로 재상담: `"recheck"`. 대기가 없거나 프로필이 다르면 409다. 보류 중 숫자와 내부 추출 기준은 API 응답·이벤트에 노출하지 않는다.

| 메서드 | 경로 | 역할 |
|---|---|---|
| GET, POST | /api/profiles/{profile_id}/experiences | 해당 프로필 경험 목록·등록 |
| PUT, DELETE | /api/profiles/{profile_id}/experiences/{experience_id} | 해당 경험 수정·삭제 |
| POST | /api/experience-coach | 대화 기반 검토용 경험 초안 |
| POST | /api/requirements/capture | 이미지에서 요건·모집 기간 초안 추출 |

프로필 생성 body에 `profile_name`과 `initial_experiences` 배열을 선택적으로 추가할 수 있다. 초기 경험 배열은 생성 시에만 사용한다.
